# Chat-bot-Ai-companion

# 💬 AI Companion Chatbot 🤖

A warm and emotionally intelligent AI companion built using **OpenAI's GPT-3.5-turbo** and deployed via **Gradio**.  
It features a stylish dark UI, voice input via microphone, and AI voice replies using `gTTS`.

---

## 🚀 Features

- 🎨 Beautiful dark-themed UI
- 💬 GPT-powered responses with emotional intelligence
- 🗣️ Voice input (microphone recording)
- 🔊 Speak replies with AI-generated voice (Text-to-Speech)
- ✍️ Typing animation effect
- 🧠 Powered by `openai.ChatCompletion` API (v1.x)
